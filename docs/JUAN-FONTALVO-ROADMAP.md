# Roadmap de marca — Juan Fontalvo

Este documento ordena la idea central de la marca **Juan Fontalvo** para que la web, las redes, los servicios y los streams apunten en la misma dirección.

## Resumen rápido

| Área | Decisión |
| --- | --- |
| Marca | Juan Fontalvo |
| Frase base | PC gamer, laptops, IA y soluciones tech. |
| Ubicación | Bogotá, Colombia |
| Tono | Cercano, práctico y educativo |
| Canales prioritarios | TikTok y Kick |
| Norte de marca | Tecnología práctica para comprar, reparar, mejorar y aprovechar tus equipos. |

## Visión de marca

Juan Fontalvo no debe presentarse como una sola cosa aislada —técnico, streamer, programador o vendedor— sino como una marca tech práctica.

La idea central:

> Ayudar a personas a entender, comprar, reparar, mejorar y aprovechar mejor sus equipos usando tecnología, experiencia técnica e inteligencia artificial.

Eso permite conectar varias habilidades bajo un mismo paraguas:

- PC gamer y laptops gamer.
- Reparación y mantenimiento.
- Inteligencia artificial.
- Programación y soluciones digitales.
- Gaming y streaming.
- Compra, venta y asesoría de equipos.

## Metodología adaptada

La metodología debe combinar dos modelos:

1. **Modelo creador**: construir audiencia, confianza y autoridad.
2. **Modelo negocio/servicio**: convertir esa atención en servicios, productos y oportunidades reales.

```text
Contenido útil
→ confianza
→ comunidad
→ servicios / productos
→ casos reales
→ más contenido
```

### 1. Crear contenido desde problemas reales

No empezar desde “qué publico hoy”, sino desde problemas que la gente ya tiene:

- Mi laptop se calienta.
- No sé qué PC comprar.
- Quiero usar IA pero no sé por dónde empezar.
- Mi equipo está lento.
- Quiero hacer streaming con poco presupuesto.
- Necesito una web o automatización para mi negocio.

Cada problema puede convertirse en:

- TikTok corto.
- Directo en Kick.
- Artículo de blog.
- Servicio ofrecido.
- Caso real para mostrar autoridad.

### 2. Convertir servicios en contenido

Cada reparación, asesoría, setup o automatización puede documentarse sin exponer datos sensibles.

Ejemplo:

```text
Cliente llega con laptop lenta
→ diagnóstico
→ solución
→ antes/después
→ TikTok
→ post de blog
→ servicio ofrecido
```

Regla:

> Si resolvés algo, probablemente también podés enseñarlo.

### 3. Usar la web como centro del ecosistema

La web no debe ser solo portafolio. Debe funcionar como centro de confianza y conversión.

Debe conectar:

- Quién sos.
- Qué hacés.
- Qué servicios ofrecés.
- Qué contenido creás.
- Dónde verte en vivo.
- Cómo contactarte.
- Qué casos o resultados podés mostrar.

### 4. Separar contenido, servicio y comunidad

Cada canal cumple una función distinta:

| Canal | Función |
| --- | --- |
| TikTok | Alcance rápido y descubrimiento. |
| Kick | Comunidad, directos y confianza. |
| YouTube | Autoridad y contenido largo. |
| Web | Centro de marca, SEO y conversión. |
| WhatsApp | Cierre de servicios y ventas. |
| Newsletter futura | Relación directa sin depender del algoritmo. |

### 5. Crear casos reales como Erik Taveras

Para servicios técnicos, IA, automatización y desarrollo web, conviene mostrar casos.

Formato recomendado:

```text
Problema
→ diagnóstico
→ solución
→ resultado
→ servicio relacionado
```

Ejemplos:

- Laptop gamer con sobrecalentamiento.
- PC lenta mejorada con SSD/RAM.
- Negocio pequeño automatizado con IA.
- Web creada para vender servicios.
- Setup de streaming construido por fases.

### 6. Crear autoridad como Nate Gentile

Para contenido tech, conviene construir una voz propia:

- explicar tecnología de forma simple;
- opinar con criterio;
- recomendar sin vender humo;
- mostrar aprendizajes reales;
- hablar de IA, hardware y futuro con pensamiento propio.

La meta no es parecer experto perfecto. La meta es documentar el proceso con criterio.

### 7. Trabajar por ciclos semanales

Ciclo recomendado:

```text
Lunes: elegir 1 tema central.
Martes-miércoles: crear 2-3 piezas cortas.
Jueves: preparar directo de Kick.
Viernes/sábado: hacer directo.
Domingo: revisar qué funcionó y sacar clips.
```

Cada semana debería dejar:

- 2-3 TikToks.
- 1 directo o prueba en vivo.
- 1 idea para blog o YouTube.
- 1 aprendizaje documentado.

## Público objetivo

La marca le habla principalmente a personas que:

- Quieren comprar una PC o laptop y no saben qué elegir.
- Tienen un equipo lento, caliente, dañado o desactualizado.
- Les interesa el mundo gamer, hardware y setups.
- Quieren aprender a usar IA en la vida real.
- Buscan soluciones técnicas confiables y cercanas.
- Quieren contenido claro, sin tecnicismos innecesarios.

Ideas:

## Roadmap por fases

Objetivo: que cualquier persona entienda en segundos qué hace Juan Fontalvo.

- [ ] Ajustar descripción de YouTube.
- [ ] Ajustar descripción de Twitch.
- [ ] Definir foto/avatar y banner coherentes.
- [ ] Definir link principal hacia web o WhatsApp.

### Fase 2 — Crear contenido simple y constante

Objetivo: empezar sin esperar el setup perfecto.

Checklist:

- [ ] Publicar 3 TikToks por semana.
- [ ] Hacer 1 directo semanal en Kick.
- [ ] Guardar clips útiles del directo.
- [ ] Reutilizar clips para TikTok.
- [ ] Medir qué temas generan más interés.

### Fase 3 — Conectar contenido con servicios

Objetivo: que el contenido genere conversaciones y clientes.

Checklist:

- [ ] Cada video debe tener un llamado a la acción simple.
- [ ] Crear mensajes rápidos de WhatsApp para servicios.
- [ ] Documentar casos de reparación como contenido.
- [ ] Crear paquetes de mantenimiento y upgrades.
- [ ] Mostrar resultados antes/después.

### Fase 4 — Convertir la web en centro de marca

Objetivo: que la página deje de ser solo portafolio.

Estructura recomendada:

- Home.
- Sobre mí.
- Servicios.
- Productos.
- Blog.
- Videos.

Checklist:

- [ ] Crear página de servicios.
- [ ] Crear página de contacto con WhatsApp.
- [ ] Crear sección de redes principales.
- [ ] Crear categorías de blog.
- [ ] Preparar estructura para productos recomendados.

### Fase 5 — YouTube y contenido largo

Objetivo: construir autoridad y monetización futura.

Checklist:

- [ ] Convertir temas exitosos de TikTok en videos largos.
- [ ] Crear guías de compra.
- [ ] Crear videos de reparación completos.
- [ ] Publicar comparativas.
- [ ] Usar la web para complementar cada video.

### Fase 6 — Streaming más serio

Objetivo: pasar de directos simples a un sistema estable.

Inicio:

```text
S24 Ultra → Kick
```

Futuro:

```text
S24 Ultra / cámara
→ VPS relay
→ Kick + YouTube + Twitch + TikTok
```

Checklist:

- [ ] Mejorar audio.
- [ ] Mejorar iluminación.
- [ ] Definir overlays básicos.
- [ ] Organizar escenas y títulos.
- [ ] Evaluar multistream cuando ya haya constancia.

### Fase 7 — Agentes de IA para el trabajo diario

Objetivo: que la IA ayude por flujo, no como chat suelto.

Agentes recomendados:

| Agente | Para qué sirve |
| --- | --- |
| Estrategia | Ordenar ideas, prioridades y calendario. |
| Contenido | Crear hooks, guiones, títulos y clips. |
| SEO/blog | Convertir ideas en artículos posicionables. |
| Comercial | Crear cotizaciones, mensajes y respuestas a clientes. |
| Técnico | Crear checklists de diagnóstico y reparación. |
| Streaming | Preparar directos, títulos, temas y clips. |
| Web | Mejorar estructura, copy y secciones de la página. |

Flujo recomendado:

```text
Idea suelta
→ Agente de estrategia
→ Agente de contenido / SEO / comercial
→ Publicación en TikTok, Kick, web o YouTube
→ Revisión de resultados
→ Mejora del siguiente contenido
```
